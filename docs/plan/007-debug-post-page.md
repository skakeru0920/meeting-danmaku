## ゴール

入力欄と送信ボタンだけの画面を用意し、Zoom 接続なしで任意の本文を overlay へ流して
見た目を調整できるようにする。

## 手順

1. `/debug` に入力欄 + 送信ボタンのみの画面を用意する
2. 送信内容をサーバー経由で overlay へ流す
3. 本文は `textContent` で挿入する(`innerHTML` にユーザー入力を渡さない)
4. `<script>alert(1)</script>` を投稿して挙動を見る

## 完了条件

- `/debug` で入力した文字列が overlay に流れる
- `<script>` を投稿してもスクリプトとして実行されず、文字列として流れる
