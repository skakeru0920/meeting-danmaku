## ゴール

Plan 002 で選ばれた表示方式で、Zoom の画面共有にコメントを重ねて
発表者自身と別 participant の両方に見せられることを、本物のチャットで通しで確認する。

## 前提: 方式は Plan 002 の結果で決まる

- Plan 002 の必須(2) が**成功** → Electron の透過ウィンドウがデスクトップ全体共有に映るので、
  通しで動くかの確認だけになる。OBS は不要。
- Plan 002 の必須(2) が**失敗** → 視聴者向けに OBS Browser Source を使う。
  overlay の URL を OBS の Browser Source に設定し、背景が透過することを確認する。

着手前に Plan 002 の結果を読み、どちらの手順を実行するか確定させること。

## 手順

1. Plan 002 の結果を確認し、方式を確定する
2. Zoom ミーティングを開き、画面共有を開始する
3. 別 participant から Everyone 宛に投稿する
4. 発表者自身の画面と、別 participant の画面の両方で見え方を確認する

## 完了条件

- **目的 1**: 画面共有中、発表者自身の画面にコメントが流れて見える
- **目的 2**: 別 participant の画面にもコメントが流れて見える
- overlay の背景が黒などで塗り潰されていない
- DM が流れていない

## Spike

### 仮説

Plan 002 で確認した表示方式が、実際の Zoom チャットを流したときも
遅延なく成立し、目的 1 と目的 2 の両方を満たす。

上記「手順」がそのまま検証手順。投稿から表示までの体感遅延も観測する。
